About this tool

A QR code is a two-dimensional barcode that any smartphone camera can read in a fraction of a second. This free QR code generator turns any text, website link, Wi-Fi login, or short message into a crisp, scannable QR code — entirely inside your browser. Because everything runs locally with JavaScript, the text you encode is never sent to a server, which makes this generator safe for sensitive content like private links, internal URLs, or contact details.

You control the output: pick from three image sizes (256, 512, or 1024 pixels), choose an error-correction level, and even customize the foreground and background colors. Higher error correction lets the code stay readable even if part of it is damaged, smudged, or partially covered — useful for printed flyers, product packaging, and outdoor signs. The finished QR code downloads as a PNG with a clean white margin (quiet zone) so scanners recognize it instantly.

Pro tips

Print at the right size. For business cards, keep the QR at least 2×2 cm; for posters viewed from 2 meters away, go 10 cm or larger. A code too small for its scanning distance is the #1 reason QR codes fail in the real world.

Always test before you print. Scan the downloaded PNG with two different phones (one iPhone, one Android) before sending it to a printer. Catching a typo in the URL now saves a costly reprint later.

Leave quiet zone. The white margin around a QR code is part of the code — scanners need it. Never crop the image tight or place text touching its edges.

Frequently asked questions

Do QR codes expire?

No. A QR code is just a visual encoding of text — it never expires on its own. If the code contains a website link, it keeps working as long as that website stays online.

Which error-correction level should I choose?

Level M (15%) is the best all-rounder. Use Q or H if the code will be printed small, placed outdoors, or might get scratched or dirty. Higher levels make the code slightly denser.

Is there a limit on how much text I can encode?

Yes — a QR code holds up to about 4,000 alphanumeric characters. Very long text creates a denser code that is harder to scan from a distance, so keep URLs short when possible.

Can I use the generated QR codes commercially?

Yes — 100%. Every QR code you create here is yours to use on products, packaging, flyers, business cards, or client work with no attribution required and no licensing fee, forever.

Why won't my QR code scan?

The three usual culprits: the code is printed too small for the scanning distance, there is not enough white margin (quiet zone) around it, or the encoded text has a typo. Regenerate at 1024px, keep a clear margin, and test with two phones.

What is the difference between static and dynamic QR codes?

This generator makes static QR codes — the destination is baked into the pattern permanently and they never expire. Dynamic codes (which need a paid service) let you change the destination later and track scans. For most uses — menus, Wi-Fi, contact cards — static is all you need.
