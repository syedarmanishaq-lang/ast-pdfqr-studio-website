About this tool

Encode text or images to Base64 and decode Base64 back to readable text. This free Base64 tool is a staple for developers and curious tinkerers: encode an image to embed it directly in HTML or CSS as a data URI, decode a suspicious string you found in a config file, or prepare binary data for APIs that only accept text.

Base64 represents binary data using 64 safe ASCII characters, which is why it shows up in email attachments, JWT tokens, and embedded web assets. Note that Base64 is an encoding, not encryption — anyone can decode it, so never use it to hide secrets. All conversion runs locally in your browser.

Frequently asked questions

What is Base64 used for?

Embedding images in HTML/CSS as data URIs, encoding binary data for text-only systems like email (MIME) and JSON APIs, and representing tokens like JWTs.

Is Base64 encryption?

No — it is just an encoding. Anyone can decode Base64 instantly, so it provides zero security. Never use it to protect passwords or secrets.

Why does encoded output look ~33% larger?

Base64 uses 4 characters to represent every 3 bytes of data, so output is always about one-third larger than the input.
