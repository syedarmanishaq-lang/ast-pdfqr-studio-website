About this tool

Get instant intelligence on any PDF. This free PDF analyzer reports the page count, file size, document metadata (title, author, creation date, producer software), and full word and character statistics — all within seconds of opening the file. It is useful for auditing documents before publishing, checking what metadata a file leaks, or quickly sizing up a long report.

Metadata inspection is a genuine privacy feature: PDFs often carry hidden author names, editing software, and timestamps you may not want to share. This tool surfaces all of it so you can decide what to strip before distributing a file. Analysis is 100% local — your document is parsed in the browser and never uploaded.

How to use

  1. Open or drag in your PDF file.

  3. Review the metadata table for hidden info.
  4. Use the word stats for reports or publishing checks.

Frequently asked questions

What metadata can a PDF contain?

Title, author, subject, keywords, creator software, producer, and creation/modification dates. Many files carry more than their owners realize.

Can I remove metadata with this tool?

The analyzer shows metadata but does not edit files. To strip it, re-export the PDF from clean software or use a dedicated metadata remover.

Is my document uploaded anywhere?

No. The file is parsed locally by JavaScript in your browser tab and never leaves your device.
